# InterPoll icon explorations — 10 concepts

Ten additional directions generated for comparison. The contact sheet is the quickest way to scan them; each concept folder contains the 1024px master plus PWA and favicon previews.

Files in each concept folder:

- `master-1024.png` — source artwork
- `pwa-512.png` — large PWA icon
- `pwa-192.png` — PWA icon
- `favicon-32.png` — favicon preview

`contact-sheet.png` shows all ten concepts together. Existing files in `public/` were not changed.
